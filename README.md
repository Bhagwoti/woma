# Woma — Your Finance Buddy

**Woma** is a sleek, lightweight, and powerful work and pay tracker designed to help freelancers, shift workers, and contractors manage their earnings with ease. 

## ✨ Features

- **Toggleable Stats**: Switch seamlessly between **This Month** and **All Time** performance overviews.
- **Custom Shift Rates**: Set a global hourly rate or override it for specific shifts.
- **Flexible Viewing**: Filter your shift history by Day, Week, Month, or view everything at once.
- **Payment Tracking**: Mark periods as paid and maintain a clear history of your income.
- **Data Portability**: Export your entire database as a JSON backup and import it on any device.
- **Sleek Aesthetics**: A modern, responsive design built with a focus on typography and usability.
- **Privacy First**: All data is stored locally in your browser's `localStorage`—no servers, no tracking.

## 🚀 Getting Started

Woma is a standalone web application. To get started:

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Set your hourly rate and start logging your shifts!

## 🛠️ Built With

- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom design system with variables for easy theming.
- **Vanilla JavaScript**: Lightweight logic with no external dependencies or frameworks.
- **Local Storage API**: Persistent data storage.

## 💾 Data Management

Woma stores your data directly in your browser. To ensure you never lose your records, we recommend using the **Export Backup** feature in the Settings menu periodically. You can use the **Import Backup** feature to transfer your data to a different browser or device.
